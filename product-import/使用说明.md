# HLC 产品资料 Excel 导入

1. 打开固定导入表 `C:\Users\Sam\Desktop\HLC_产品资料导入表.xlsx`。
2. 在“产品基础信息”“产品内容与SEO”“产品图片”填写同一个产品URL标识。
3. 在“产品基础信息”的“所属目录”选择对应类别，发布时产品会同步到对应的独立产品目录页：
   - `竹纤维面料` → `/textile/bamboo-fabric/`
   - `丝光&液氨` → `/textile/mercerized-liquid-ammonia-fabric/`
   - `功能性面料` → `/textile/functional/`
   - `羊毛面料` → `/textile/wool-fabric/`
   - `砂洗针织面料` → `/textile/womenswear-fabric/`
   - `常规针织面料` → `/textile/knitted-fabric/`

   旧表格中的 `绣花面料` 会兼容映射到新的常规针织面料目录，但新资料请统一使用 `常规针织面料`。
4. 图片可直接插入黄色图片格，或填写本地图片绝对路径。
5. 测试结果可填写文字；如需显示高清测试报告，可把 PDF、JPG、JPEG、PNG、WEBP 或 GIF 文件路径填写到“测试结果图片路径（可选）”。本地 PDF 会自动转换为 300 DPI PNG。旧版表格也可以直接把文件路径填入“测试结果（英文）”。
   - 原始测试报告图片或 PDF 路径会继续保留并显示为证据。
   - 有测试报告时，可在“详细信息（英文）”填写经报告确认的测试项目文字摘要；系统会放入 “Fabric Test Summary”，不会自动推测标准、数值或测试结论。
   - 测试报告 ALT 优先使用“测试结果图片ALT（英文）”；旧表格会复用包含 test/report/result 的图片 ALT。仍未填写时，系统只按产品名称和 Style# 生成中性 ALT。
   - 不要把测试报告全文堆进产品描述或 SEO 标题。只有报告明确提供项目、标准和结果时，才填写对应文字；颜色、批次或买家要求可能改变结果时，应明确说明。
6. 将“发布”改为 `YES`，保存并关闭 Excel。
7. 在 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File E:\hlctex-site\product-import\更新产品.ps1
```

脚本会：

- 生成或更新 `/textile/products/<产品URL标识>/index.html`
- 复制本地或 Excel 内嵌图片到 `/assets/products/<产品URL标识>/`
- 将测试结果图片复制为产品独立资源，并在“Test results”标签中直接显示；点击可查看原图
- 写入产品标题、价格、规格、内容标签和相关产品
- 生成 Product JSON-LD，包括 `offers`、实时价格和有效期
- 更新 `sitemap.xml`

生成完成后，请先检查 Git 修改，再提交并推送到 GitHub。
